Measured accuracy by model

{{ ranked().length }} run(s)

Scored under the shipped decision band (AI ≥ {{ ranked()[0]?.ai_cut ?? '0.69' }}, HUMAN ≤ {{ ranked()[0]?.human_cut ?? '0.40' }}). Separation is median(AI texts) − median(human texts): the bigger it is, the less a threshold choice matters. Deferred means the model landed inside the band and the tie-break lane had to answer; a deferral counts as not-correct here, because this column scores each model standing alone, before the tie-break gets a say. correct + wrong + deferred = n scored. A text with no score is either no answer (the gateway or its upstream failed -- an HTTP 429/5xx, a dropped connection: nothing the model did) or a bad answer (it replied in a form carrying no score). They are different defects with different fixes, and merging the two silently blames the model for the gateway.
