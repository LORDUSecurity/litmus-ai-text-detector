# Provenance and Metadata Checks  
C2PA-style content credentials are becoming standard for generative media. For example, Adobe/Intel’s Content Authenticity (C2PA) “Content Credentials” specification (supported by companies including OpenAI, Google, Meta, etc.) lets tools embed provenance metadata in generated files.  In practice, services like OpenAI’s verification tool read C2PA metadata in images or documents to flag AI generation.  (In plain text, such metadata is usually absent unless the text was exported from a signed file.)  Some tools or platforms may sign their output (e.g. a signed report or hidden JSON), but no universal text-only signature is widely used yet.  

# Watermark Detection  
Several large-model providers plan invisible watermarks in text.  Google’s *SynthID* system (now open-sourced) can insert a statistical watermark and detect it with a binary classifier.  SynthID’s detector (available in Hugging Face Transformers) outputs whether a passage carries the watermark or not.  Anthropic’s Claude also embeds a hidden watermark in its text; it has released a regulators-only API for checking it (non-public).  (OpenAI’s own watermarking for ChatGPT text remains unannounced.)  In practice, one can run available detection code: for instance, Hugging Face offers a SynthID text-detector pipeline (free/open-source) to check Google-generated text.  A detected watermark immediately flags “AI-generated” and can often identify the model provider.  

# Statistical Analysis and Classifier Models  
When metadata or watermarks are absent, statistical features are used.  Open-source detector models are available: for example, a **DistilBERT**-based classifier fine-tuned to distinguish AI vs human text, and a **RoBERTa**-based “SuperAnnotate AI Detector” trained on multi-LLM outputs.  These sequence-classification models output an AI-score for given text.  Other open tools include **GLTR** (Giant Language Model Test Room), which highlights unlikely token choices based on a GPT model, and **DetectGPT**, a zero-shot method analyzing the curvature of an LLM’s log-probability surface for text.  In practice one runs these via Python: e.g. Hugging Face’s `pipeline("text-classification")` on one of these models yields AI likelihood.  All these are free/open-source (MIT/Apache licensed) and can be self-hosted.  

# Paid vs. Free Services (Including OmniRoute Providers)  
**Commercial detectors:**  Turnitin’s AI-writing report, Originality.ai, Grammarly’s detector, etc., are paid services (generally via institution or subscription) that combine proprietary models and thresholds.  *GPTZero* (Superhuman) offers a free scanner for short text with optional paid tier.  **OpenAI’s text classifier** was retired in 2023 due to low accuracy.  

**Free models/providers:**  Many large LLM providers offer free tiers accessible via API or tools.  OmniRoute (an open-source AI gateway) aggregates these.  For example, OmniRoute’s documentation lists **Google Gemini** (free-tier models), **Cloudflare AI** (Llama 3.3, Gemma 3, Mistral with 10K tokens/day), **Scaleway AI** (Qwen-3 235B with 1M tokens), **NVIDIA NIM** (free developer access to 70+ models), and **Cerebras Cloud** (1M tokens/day on Llama3 70B).  OmniRoute also provides Inflection’s **Kimi K2/K2.5** (via “Qoder”) and Z-AI’s **GLM-4.7**, etc.  Many of these free services can be queried via Hugging Face inference or REST APIs.  Other notable free LLMs include Meta’s LLaMA variants (via open weights or inference), GPT-J/NeoX (EleutherAI), and Cloudflare’s free model endpoints.  

# Integration and Pipeline Flow  
A recommended pipeline is:  
1. **Check for content metadata:** If the text comes from a file format that can hold C2PA/Credential data, use a C2PA verifier (e.g. Adobe Content Credentials tools) or OpenAI’s Verify Content API (for images/audio) to see if provenance tags an AI source.  
2. **Watermark scan:** Pass the text through SynthID or similar detectors. For example, use Hugging Face’s *SynthID-text* detector to test for Google’s watermark. If a watermark is found, flag AI and note the model (e.g. “Generated by Google Gemini”). If the source is Claude, an internal API could be used (limited availability).  
3. **Statistical classifier:** If no watermark, compute features and run a trained classifier. For instance, use a pipeline on a DistilBERT or RoBERTa detector model to get an AI probability. Optionally also compute perplexity or token z-scores (as GLTR does). If the AI-score exceeds a threshold, label it “AI-generated.” Otherwise, mark it “Likely human.”  
4. **Reporting:** Return the label plus confidence or probability. (“AI-generated with 92% confidence,” or “Likely human (no strong AI signal).”)  

Throughout, free and paid options can be mixed. For example, one could set up OmniRoute locally and add free-model providers (NVIDIA, Cerebras, Cloudflare, etc.) to automatically fallback among models.  Alternatively, cloud inference APIs (OpenAI, Hugging Face Inference, Cohere, AI21) can be plugged in at each step.  In sum, use open-source detectors (GLTR, DetectGPT, DistilBERT) and providers (OmniRoute’s free catalog) wherever possible, resorting to paid services (Turnitin, GPTZero’s premium, Anthropic/Google APIs) for higher-stakes or more accurate checks.
